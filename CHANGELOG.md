# Changelog

- Added detector-declared collection prerequisites and fixed unknown-file handling.
- Added an explicit superseded lifecycle for detector-version transitions.
- Added an explicit monotonic R0-R6 risk model.

- Added a pilot evidence report that cannot automatically approve the mutation gate.
- Added reproducible non-root containers and a turnkey Compose deployment.
- Hardened CI with frozen installs, concurrency controls, and commit-pinned actions.
